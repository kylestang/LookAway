## Fork improvements

This is a fork of [Praseetha-KR/LookAway](https://github.com/Praseetha-KR/LookAway) with the following improvements:

- Choose which days of the week reminders are active
- Fixed scheduling for time windows that cross midnight or end before the next reminder
- Notifications dismiss themselves after 20 seconds
- Installable via Obtainium
